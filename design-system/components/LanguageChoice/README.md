# LanguageChoice

The list of languages, used on first open and in the Language sheet.

- One card, one row per language, at least 72 tall. The name in its own script at 22, with a short hint in `small` `muted`, like Chinese, with pinyin.
- The chosen row uses `current` with a filled `primary` circle and a white tick. Others show an empty circle in `line`.
- On first open nothing is chosen until you tap, and Start stays disabled until then.
- In the Language sheet, tapping a row switches right away and closes the sheet, with a toast like Now practicing Spanish.
