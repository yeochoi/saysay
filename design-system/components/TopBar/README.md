# TopBar

The top of the main screen.

- SaySay in Quicksand 700 at 20, the same letters as the icon, so the name and the icon read as one mark.
- The language pill sits next to the name. `soft` fill, semibold 15 in `accent-text`, the language in its own script, like 中文 or Español, and a small down chevron. Tapping it opens Language.
- Three flat round buttons at the right, 6 apart. `chip`, 44 wide, a 20 icon with a 2 line in `ink`, no shadow. + opens New sentence, the list icon opens Sentences, the sliders icon opens Settings.
- + comes first because adding a sentence you just heard should take one tap.
- Nothing else lives here.
