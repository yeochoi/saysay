# TopBar

The top of the main screen.

- SaySay in Quicksand 700 at 20, the same letters as the icon, so the name reads as the logo.
- Three flat round buttons at the right, 8 apart. `chip`, 44 wide, a 20 icon with a 2 line in `ink`, no shadow. + opens New sentence, the list icon opens Sentences, the gear opens Settings.
- + comes first because adding a sentence you just heard should take one tap.
- The language is not here. Switching lives in Settings under Practicing, so the top stays calm.
- Nothing else lives here.
